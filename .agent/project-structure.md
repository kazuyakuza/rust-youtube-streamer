- app/ - application orchestration: CLI parsing and dispatch, startup pipeline, logging initialization, error boundaries, the `demo` mode, the production `run` mode (with the Phase-07 stream-backed chat worker), the frame pipeline, the interactive `auth` mode, and the opt-in pipeline diagnostics collector (disabled by default)
