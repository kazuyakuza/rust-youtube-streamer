### Technical & Architecture decisions (global)
1. Script: POSIX sh, ≤100 lines, helper-function style; runs all four checks ALWAYS (aggregate results; a fmt mismatch does not prevent check/test/clippy from running — cascading failures after `check` failure are acceptable and reported).
2. Output shape per command: `== name ==` header, then merged `2>&1` stream (goes to MCP capture AND per-check log), then `PASS|FAIL name exit=<code>` line. Summary block at end. Script exit 0 all-pass / 1 any-fail.
3. Log artifact: `logs/checks/<UTC-timestamp>.log` created via `mkdir -p logs/checks` + `date -u +%Y%m%dT%H%M%SZ`; env header (UTC time, cargo version) printed to log+stdout.
4. NO fmt auto-apply (pure verification; diff printed on mismatch).
5. Invocation contract documented: single MCP command `docker compose -f /rust-youtube-streamer/docker-compose.yml run --rm rust sh scripts/dev-checks.sh`.
6. Semver: tooling-only change → no Cargo version bump (Step 3 documented no-op).
7. Git: branch `feat/dev-checks-script`.
